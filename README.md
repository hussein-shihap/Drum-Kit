Drum Kit 🥁
An interactive drum kit web application that lets users play different drum sounds using keyboard keys or on-screen buttons.
Features
•	Play different drum sounds using keyboard keys
•	Play sounds by clicking the drum buttons
•	Interactive button animations
•	Responsive and simple interface
Tech Stack
•	HTML5
•	CSS3
•	JavaScript
•	Audio API
How It Works
The application listens for keyboard and mouse events and triggers the corresponding drum sound when a user interacts with a drum button.
Getting Started
1.	Clone the repository:
git clone https://github.com/hussein-shihap/Drum-Kit.git
2.	Open the project folder.
3.	Open index.html in your browser.
4.	Press the assigned keyboard keys or click the drum buttons to play the sounds.
